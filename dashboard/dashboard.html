Tải Space Offline Thành Công!

Đã tải dữ liệu xuống máy tính của bạn.

📖 Hướng dẫn sử dụng:
  1. Nếu tải file ZIP: Giải nén file ZIP vào một thư mục trên máy tính và mở file index.html.
  2. Nếu tải từng file: Các tệp HTML đã được lưu trực tiếp vào thư mục Downloads của bạn theo đúng thư mục phân cấp.
  3. Bạn có thể mở bất kỳ file HTML nào để xem nội dung offline mà không cần kết nối mạng.
